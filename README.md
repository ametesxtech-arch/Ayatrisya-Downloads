# Ayatrisya Desktop Downloads

Official release repository for **Ayatrisya Desktop** by Ametesx.

This repository hosts platform-specific desktop installers and release information for users downloading Ayatrisya.

## Downloads

Download installers from the [GitHub Releases page](https://github.com/ametesxtech-arch/Ayatrisya-Downloads/releases).

| Platform | Package | Status |
|---|---|---|
| Windows x64 | NSIS installer (`.exe`) | Available when published in a release |
| Linux x64 | AppImage (`.AppImage`) | Available when published in a release |
| macOS | Universal disk image (`.dmg`) | Available when published in a release |

Only use installers attached to published releases in this repository. Check each release's notes and platform requirements before installing.

## Verify downloads

When provided in the release metadata, verify the downloaded file against its published SHA-256 checksum before running it. Do not use a checksum from a different version or platform.

## Release information

Each published release should include:

- A version tag and release title
- Release notes describing changes and known limitations
- The appropriate installer assets for supported platforms
- Accurate file sizes and SHA-256 checksums

Ayatrisya downloads should only be marked as verified when the corresponding build and test evidence is available.
