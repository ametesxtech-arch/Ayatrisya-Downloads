# AYATRISYA — MASTER UI DEVELOPMENT PROMPT
## Build the Complete Premium AI Workspace Interface from Scratch

Act as an elite product designer, senior frontend architect, UI/UX specialist, design systems engineer, and creative director.

Your task is to design and implement the complete frontend UI for **Ayatrisya**, an ambitious AI workspace built by Ametesx.

Do not create a generic AI chatbot clone. Create a distinctive, premium, cinematic, production-quality interface that feels like a serious technology product combining an AI assistant, creative studio, document workspace, research environment, and desktop coding companion.

The current development phase is **UI ONLY**.

Our development sequence is:
1. Complete and polish the entire UI.
2. Develop and integrate our own AI models trained by our team. We will not use third-party AI inference APIs.
3. Implement local-first storage, desktop filesystem access, and optional Google Drive integration.

Respect this sequence. Build the interface now without prematurely implementing the AI models, cloud database, storage engine, OAuth, or paid subscription system.

# 2. DESIGN DIRECTION

Create a premium dark-first interface with restrained glassmorphism, layered depth, subtle lighting, refined typography, precise spacing, and cinematic transitions.

Use:
- Near-black and deep charcoal backgrounds
- Graphite and slate surfaces
- A distinctive violet-indigo primary accent
- Restrained electric blue accents for interactive states
- Soft white and cool-grey typography
- Fine borders and subtle shadows
- Clear visual hierarchy
- Generous negative space
- Carefully controlled gradients
- Consistent iconography
- Elegant micro-interactions

Avoid:
- Excessive neon
- Rainbow gradients everywhere
- Generic AI illustrations
- Giant rounded cards on every section
- Excessive glass panels that reduce readability
- Random emoji used as interface icons
- Fake statistics, fake reviews, fake users, and fake performance claims
- Overloaded dashboards
- Unnecessary animations
- Cloned ChatGPT, Cursor, Linear, or other product interfaces

Use a consistent design token system for colors, typography, spacing, radii, shadows, motion, and responsive breakpoints.

Use a high-quality sans-serif typeface such as Inter or another appropriate locally available or properly loaded font.

Prefer Lucide icons or a consistent equivalent. Never mix unrelated icon styles.

# 3. FIRST ACTION: AUDIT THE EXISTING REPOSITORY

Before changing files:
1. Inspect the complete existing project structure.
2. Identify the framework, current dependencies, routing, styles, assets, and reusable components.
3. Identify which existing pages or components are functional.
4. Preserve valuable existing code and assets.
5. Do not delete working functionality just to replace it with a new template.
6. Create a concise implementation plan and then proceed with the work.
7. If the repository already contains an Ayatrisya or Ametesx frontend, improve it instead of blindly rebuilding it.

Use the existing package manager and project conventions wherever possible.

Do not expose environment secrets or copy them into frontend source code.
